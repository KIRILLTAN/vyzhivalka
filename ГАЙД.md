## Какие файлы есть и зачем

Всё лежит в папке `E:\Выживалка`:

| Файл | Что это | Куда загружать |
|---|---|---|
| `dist\VyzhivalkaSetup.exe` | **Установщик.** Внутри игра с лаунчером. Ставит игру, делает ярлыки и обновляет её. | **В каждый релиз — только этот один файл** |
| `VyzhivalkaOnline.exe` | **Онлайн-установщик** (8 МБ). Всегда сам скачивает с GitHub *последний* установщик и запускает его. Обновлять его не нужно никогда. | Один раз, вместе с кодом в репозиторий |
| `dist\Vyzhivalka.exe` | Сама игра (её ставит установщик) | Никуда, она уже внутри Setup |
| Остальное (`game\`, `*.py`, `build.bat`, …) | Исходный код | В репозиторий |

Как это работает у друга:
**VyzhivalkaOnline.exe** → скачивает **последний VyzhivalkaSetup.exe** → тот ставит игру → на рабочем столе появляется ярлык **«Выживалка»** → он открывает **лаунчер** (новости, ник, кнопка «Играть») → когда вы выпускаете новую версию, в лаунчере появляется кнопка **«ОБНОВИТЬ»**.

## Шаг 1. Аккаунт GitHub

1. Откройте https://github.com/signup
2. Введите email, придумайте пароль, ник — **KIRILLTAN**.
3. Подтвердите email (придёт письмо с кодом).

Если аккаунт уже есть, просто войдите: https://github.com/login

## Шаг 2. Создать репозиторий

1. Откройте https://github.com/new
2. **Repository name:** `vyzhivalka` (ровно так, маленькими латинскими буквами).
3. **Description:** `Зомби-выживалка с друзьями` (можно любое).
4. Выберите **Public**. Это обязательно, иначе установщик и лаунчер не увидят релизы.
5. Галочки *Add a README file*, *.gitignore* и *license* **не ставьте**.
6. Нажмите зелёную кнопку **Create repository**.

Готово: https://github.com/KIRILLTAN/vyzhivalka

## Шаг 3. Загрузить код (выберите один способ)

### Способ А — через сайт, ничего ставить не надо
1. Откройте https://github.com/KIRILLTAN/vyzhivalka/upload/main
   Если страница не открылась, на странице репозитория нажмите синюю ссылку **«uploading an existing file»**.
2. Откройте в Проводнике папку **`E:\Выживалка\ЗАГРУЗИТЬ_НА_GITHUB\1_КОД - перетащить в репозиторий`**, нажмите **Ctrl+A** и **перетащите всё мышкой в окно браузера**. Там уже только нужное: папка `game`, все `.py` и `.bat`, гайд и `VyzhivalkaOnline.exe`.
3. Подождите, пока все файлы загрузятся (полоски исчезнут), и внизу нажмите зелёную **Commit changes**.

### Способ Б — через Git (удобно для частых обновлений)
1. Скачайте и установите Git: https://git-scm.com/download/win
   Все настройки оставьте по умолчанию: Next → Next → Install.
2. В папке `E:\Выживалка` дважды щёлкните **`publish.bat`**.
3. При первом запуске:
   - скрипт спросит email от GitHub — введите его и нажмите Enter;
   - откроется окно входа в GitHub — нажмите **Sign in with your browser** и подтвердите в браузере.
4. Скрипт сам загрузит весь код вместе с `VyzhivalkaOnline.exe`.

## Шаг 4. Создать первый релиз (один файл!)

1. Откройте https://github.com/KIRILLTAN/vyzhivalka/releases/new
2. Нажмите **Choose a tag**, впишите `v1.2.0` и нажмите **Create new tag: v1.2.0 on publish**.
   Тег должен совпадать с версией игры (`VERSION` в `game\config.py`), только с буквой `v` впереди.
3. **Release title:** `Выживалка 1.2.0`
4. **Описание.** Напишите списком, что есть в игре или что нового. **Этот текст покажется в лаунчере в разделе «Новости».** Например:
   ```
   - Бесконечный мир: города, фермы, леса, военные базы
   - Торговцы, охрана и бандиты
   - Сохранения игры
   - Стройка своего дома, добыча дерева, камня и ягод
   - Машины с тюнингом, мультиплеер по сети
   ```
5. Перетащите в область **«Attach binaries by dropping them here»** один файл: **`VyzhivalkaSetup.exe`** из папки `ЗАГРУЗИТЬ_НА_GITHUB\2_РЕЛИЗ - один файл в Releases`. Дождитесь загрузки (≈33 МБ).
   Имя файла не меняйте: установщик и лаунчер ищут именно `VyzhivalkaSetup.exe`.
6. Нажмите зелёную **Publish release**.

## Как выпустить обновление (каждый раз)

1. Внесите изменения в игру.
2. Откройте `game\config.py` и увеличьте версию, например `VERSION = "1.3.0"`.
3. Дважды щёлкните **`build.bat`** и дождитесь надписи «Готово!» (≈3 минуты).
4. Загрузите код: Способ А (перетащить изменённые файлы на https://github.com/KIRILLTAN/vyzhivalka/upload/main) или **`publish.bat`**.
5. Создайте релиз https://github.com/KIRILLTAN/vyzhivalka/releases/new:
   - тег `v1.3.0`;
   - список изменений в описании;
   - **один файл** `dist\VyzhivalkaSetup.exe`;
   - **Publish release**.

Что увидят игроки:
- в **лаунчере**: кнопка **ОБНОВИТЬ** и ваш текст в новостях. Нажали — скачался новый Setup, поставился, лаунчер открылся снова;
- в **меню игры**: строка «Доступна новая версия» и кнопка **Обновить**, она работает так же;
- **онлайн-установщик** сам будет скачивать уже новую версию.

> Важно: в мультиплеере у всех должна быть одинаковая версия игры. После релиза попросите друзей нажать «Обновить».

## Игра с друзьями по сети

### В одной сети (общий Wi-Fi или роутер)
1. Хост: **Мультиплеер → Создать комнату** → выбрать «Мир» (новый или сохранение) → **Создать комнату**.
2. Windows спросит про доступ к сети: отметьте галочки и нажмите **Разрешить доступ**.
3. Вверху лобби появится **код комнаты**, например `52C-J2A9`. Отправьте его друзьям.
4. Друзья: **Мультиплеер → Найти комнату** → ввести код → **Войти**.
5. Хост нажимает **Начать игру**. Кнопкой **Кикнуть** можно выгнать игрока.

### Из разных домов — Radmin VPN (бесплатно)
1. Все ставят Radmin VPN: https://www.radmin-vpn.com/ru/
2. Хост: **Сеть → Создать сеть**, придумывает имя и пароль.
3. Друзья: **Сеть → Присоединиться к существующей сети**, вводят это имя и пароль.
4. Хост создаёт комнату и жмёт **«Другая сеть»**, пока слева вверху не появится **Radmin VPN**. Этот код отправляет друзьям.

### Если не подключается
- У всех одна версия? (видно внизу лаунчера)
- Брандмауэр у хоста: **Пуск → «Разрешение взаимодействия с приложениями через брандмауэр»** → **Изменить параметры** → найти `Vyzhivalka` → отметить «Частная» и «Публичная».
- Вместо кода можно ввести IP хоста — он написан слева вверху в лобби.
