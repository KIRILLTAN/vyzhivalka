# Выживалка

Зомби-выживание с видом сверху для одного игрока или для компании друзей по локальной сети.

## Что есть в игре

- **Бесконечный мир**: он достраивается по мере того, как вы идёте. В нём есть биомы: центр города, город, пригород, фермы с полями и амбарами, леса с хижинами, пустоши, парки с прудами, военные базы, лагеря торговцев и бандитов. На карте (M) видно всё исследованное.
- **Выжившие**:
  - торговцы (жёлтые) — покупка и продажа за деньги;
  - охранники и бродячие выжившие (зелёные) — помогают отбиваться от зомби; с выжившими тоже можно торговать;
  - бандиты (красные) — нападают сразу; бродят группами и сидят в своих лагерях.
  
  У каждого выжившего свой инвентарь, после смерти он остаётся на теле. Если ударить дружелюбного, он и его друзья станут вашими врагами.
- **Сохранения**: игра сохраняется автоматически каждые 90 секунд и при выходе; есть кнопка «Сохранить» в меню паузы. В одиночной игре сохранения видны в списке «Продолжить», в мультиплеере мир выбирается при создании комнаты. Вещи друзей сохраняются по нику.
- **Старт за городом**: вы появляетесь у костра на пустоши, а город начинается дальше.
- **Добыча и стройка**:
  - деревья рубятся на дерево, камни разбиваются на камень, с кустов (E) собираются ягоды;
  - B открывает меню строительства и крафта: стены, деревянная дверь (зомби через неё не проходят), каменные стены, пол, сундук, кровать (точка возрождения), костёр, верстак;
  - крафтятся каменный топор, кирка, бинт, бита и шипы;
  - X разбирает свою постройку.
- **Входы в здания**: над дверью на крыше нарисован жёлтый навес со стрелкой, а к входу ведёт дорожка.
- **Деньги и торговля**: деньги находят в столах, шкафах, у зомби и бандитов. Торговец продаёт по полной цене, а покупает за половину. Каждый новый день у торговцев появляется новый товар.
- **Здания до 4 этажей** с лестницами: жилые дома, многоэтажки, магазины, полиция, больница, гаражи, склады, АЗС, казармы. Внутри комнаты, двери и мебель. Крыша скрывает то, что внутри здания, пока вы не зайдёте.
- **Лут**: холодильники, шкафы, столы, стеллажи, медшкафы, оружейные шкафы, ящики. У каждого типа своя таблица добычи.
- **Выживание**: здоровье, сытость, вода, выносливость, кровотечение. Есть смена дня и ночи, ночью зомби быстрее и их больше.
- **Зомби трёх типов**: обычные, бегуны и громилы. Они слышат выстрелы, ищут путь к вам через двери и преследуют вас.
- **Оружие**:
  - ближний бой: нож, труба, бита, монтировка, мачете, топор;
  - огнестрел: пистолет, пистолет-пулемёт, дробовик, автомат, снайперская винтовка;
  - патроны трёх калибров.
- **Модификации оружия**: глушитель, увеличенный магазин, прицел, шипы.
- **Броня**: три бронежилета и два шлема, у каждого предмета есть прочность.
- **Рюкзаки** трёх размеров.
- **Машины**: можно ездить, давить зомби, возить пассажиров (до 4 мест), следить за топливом и прочностью, заправляться на АЗС и из канистры, чинить ремкомплектом.
- **Тюнинг машин на верстаке**: двигатель, броня, шины, бак, таран, мощные фары, покраска.
- **Мультиплеер по локальной сети**: комнаты с кодом, кик игроков, настройки (атака друзей, возрождение, сохранение вещей, число игроков, количество лута и зомби, длина суток, отметки друзей на карте), чат.
- **Проверка обновлений через GitHub** в главном меню и обновление в один клик.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift | движение, бег |
| Мышь, ЛКМ | прицел, атака |
| R | перезарядка |
| Q / колесо / 1 / 2 | смена оружия |
| E | обыскать / торговать / лестница / верстак / бензоколонка |
| F | сесть в машину или выйти |
| В машине: W/S, A/D, Space | газ/тормоз, руль, ручник |
| Tab | инвентарь (ЛКМ - использовать, ПКМ - выбросить) |
| H | быстрое лечение |
| B | строительство и крафт |
| X | разобрать свою постройку |
| M | карта |
| T | чат |
| Esc | меню |
| F11 | полный экран |

## Мультиплеер

1. Создатель: **Мультиплеер → Создать комнату** → выбрать сложность и настройки → **Создать**. Вверху экрана появится **код комнаты**.
2. Друзья: **Мультиплеер → Найти комнату** → ввести код → **Войти**.
3. У создателя возле каждого игрока есть кнопка **Кикнуть**, внизу кнопка **Начать игру**.

Все должны быть в одной сети: Wi-Fi/LAN или общая VPN-сеть (Radmin VPN, ZeroTier, Hamachi). Если у хоста несколько сетей, кнопка **«Другая сеть»** показывает код для другой, например для Radmin VPN.
При первом создании комнаты Windows спросит доступ к сети: нужно **разрешить** (хотя бы для частных сетей). Используется порт TCP 47777.

## Запуск из исходников и сборка exe

```bat
pip install -r requirements.txt
python main.py
```

Сборка exe: запустите `build.bat`. Готовый файл появится в `dist\Vyzhivalka.exe`.
